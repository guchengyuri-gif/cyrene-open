# Cyrene 桌面操控插件 (Computer Use)

为昔涟 (Cyrene) 提供 Windows 原生桌面操控能力。

## 包含能力 (Tools)

1. `computer-use_get_screen_info`: 获取屏幕分辨率和当前鼠标坐标
2. `computer-use_screenshot`: 截取当前主显示器屏幕并保存为 PNG
3. `computer-use_mouse_click`: 在指定坐标执行单击/双击/右键
4. `computer-use_mouse_move`: 移动鼠标光标
5. `computer-use_mouse_drag`: 按住左键拖拽
6. `computer-use_mouse_scroll`: 滚动鼠标滚轮
7. `computer-use_keyboard_type`: 输入文本（剪贴板机制，原生支持中文字符）
8. `computer-use_keyboard_press`: 按下键盘特殊键（Enter, Esc, Tab, Ctrl+C 等）

## 安装方法

在 Cyrene 聊天界面中：
1. 点击输入栏附近的 **插件** 图标。
2. 点击右上角 **+** 号（添加插件）。
3. 选择 `cyrene-computer-use.zip` 文件导入。
4. 在已安装列表中找到 **Computer Use (桌面操控)**，点击 **启用** 即可！
